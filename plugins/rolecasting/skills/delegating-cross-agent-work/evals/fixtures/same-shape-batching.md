# Same-shape mechanical edits

Five independent configuration files each need the same already-approved field
added with a file-specific literal value. The exact files and values are known;
none of the edits changes an interface, needs design judgment, or has a distinct
test command. Each change is small enough that launching and reviewing five
separate workers would cost more coordination than the edits themselves. A
sixth task changes a public interface and needs its own design decision and test
evidence. Decide how to group the work and how the leader should review it.
