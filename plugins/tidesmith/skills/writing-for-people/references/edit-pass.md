# Edit Pass

Run this pass over the finished draft before sending, even when it reads
well.

## 1. Judge Each Dash

Scan for em dashes and for " - " used as a dash, then judge each one by
its usage. A parenthetical dash (an inserted phrase read inline) is
written unspaced: `the cache—once wired up—drops the call`. A bespoke,
non-parenthetical usage may be spaced; keep it only when the spacing is
doing work a reader would miss. Where a dash is not the best structure,
use a colon, parentheses, a semicolon, or a new sentence. Judge fit, not
count.

Check the rest of the typography while here. An en dash joins numeric
ranges (3–5) and compound modifiers built on an open compound. Inline
lists take the Oxford comma. Punctuation respects the unity of a quoted
phrase rather than intruding into it: the flag is `--force-with-lease`,
not `--force-with-lease,`.

## 2. Reread The Last Sentence

Reread the last sentence of each piece. If it lands like a mic-drop or a
tidy recap, delete it or replace it with the plain point. Shapes to
catch:

- A moral drawn from the point just made ("That's where the real cost
  hides.").
- A restatement dressed as a conclusion ("So the guard does its job.").
- A rider that adds a second ask after the first ("Also, could we…").

End on the last substantive point.

## 3. Strike On Sight

Delete or rewrite these wherever they appear:

- "worth noting", "worth also", "It's important to", "credit where due",
  "That said".
- Arrow chains (`A → B → C`) standing in for a sentence.
- Topic labels opening a piece ("On tags:", "Status:") and "I noticed".
- Any coinage you wouldn't say aloud to a colleague. Define it where it
  stands or replace it with plain words.
- Apologetic framing, hedge stacks, throat-clearing, sycophancy, and
  explanations the source already provides.

## 4. Vary Across A Batch

When sending several pieces together, compare them. If two share an
opening, a closing move, or roughly the same length, rewrite one from
its own content. Watch for several pieces in a row closing on "Also, …".

## 5. Reread As The Recipient

Read each piece as the person receiving it. Anything that reads as a
machine's note-to-self gets rewritten as speech: mechanical parallelism,
obsessive precision, restating what the reader already knows, or an
inventory that shows your work. Choose the shortest phrasing that still
sounds like speech.

## 6. Recheck Every Fact

Fluent rewriting is where facts drift: "should fail" becomes "fails", a
range becomes a point, a question becomes a commitment. Check each fact
against the brief after every rewrite, not only when first written. Full
rules: [evidence-in-prose.md](evidence-in-prose.md).
